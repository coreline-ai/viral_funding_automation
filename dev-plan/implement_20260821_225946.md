# implement_20260821_225946.md

작성 일시: `2026-08-21 22:59:46 KST`

이 문서는 X 채널 초안을 실제 게시 전에 검토하기 위한 **앱 고유의 `X 게시 전 원고 검토`** 범위를 고정한다. X UI·Post·작성기의 정밀 클론은 정책상 구현하지 않는다.

## 개발 목적

1. X 단일 1·2·3안과 X 스레드 원고의 줄바꿈·예상 가중 문자·URL·순서를 게시 전에 확인한다.
2. 선택 언어, approval snapshot, stale 상태와 검토 화면을 항상 일치시킨다.
3. desktop/mobile 읽기 폭에서 긴 URL·CJK·emoji의 가독성과 280자 경계를 확인한다.
4. 실제 X 화면·X Content·자동 게시와 분리된 local-only 검토 UI를 유지한다.

## 개발 범위

- X 탭(`x1`, `x2`, `x3`, `xThread`)에서만 `원고 | 게시 전 점검` 하위 보기 제공
- 단일안 `body`, 스레드 `segments[]`를 원본 순서·줄바꿈 그대로 text-only proof surface에 표시
- 구간별 `로컬 가중 문자 추정 / 280`, 잔여·초과, URL 수를 표시
- 선택 locale·승인 후보/승인/stale·공개 `@handle`의 안전한 읽기 전용 표시
- 넓게 `640px`, 모바일 `390px`, 실제 320px responsive·keyboard·forced-colors·reduced-motion 대응
- 순수 immutable model, browser static module allowlist, DOM/브라우저 회귀 테스트
- X 문자 계산기가 실제 자동 게시 정본이 아니라 로컬 추정치임을 고지

## 잔여 리스크 / 후속 과제

- X 정책·UI·문자 계산은 변경될 수 있다. actual write 또는 실제 X Content 표시를 시작하는 날에 공식 문서를 다시 검토한다.
- 현재 가중 문자 계산기는 `twitter-text`와 완전 동치가 보장되지 않으므로 v1 UI의 표현은 추정치다.
- 이 기능은 실제 X의 URL 표시, 줄 접기, 미디어, reply 연결, 계정별 UI·Premium 장문을 재현하지 않는다.
- 실제 X API write, 사용자 동의, OAuth scope, token vault, idempotency, live-result display는 별도 개발 계획에서만 다룬다.
