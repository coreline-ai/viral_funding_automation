# implement_20260822_083934.md

작성 일시: `2026-08-22 08:39:34 KST`

이 문서는 X·Threads 다음으로 남은 17개 소셜/커뮤니티/launch 서비스의 **게시 전 로컬 미리보기**를 한 플랫폼씩 구현하기 위한 작업 문서다. 실제 게시 자동화 개발은 이 계획의 범위가 아니다.

`2026-08-22` 재검토: 이 문서는 전체 화면을 한꺼번에 만들지 않는다. 각 서비스를 시작할 때 해당 서비스의 공개 정보 구조·현재 입력 계약·공식 운영 제약을 다시 확인하고, **한 서비스의 model → 화면 → 안전/반응형 QA가 끝난 뒤에만** 다음 서비스로 넘어간다. 현재 완료로 인정된 것은 LinkedIn, Facebook, Instagram, YouTube Shorts, TikTok, Product Hunt, Peerlist, Disquiet, Reddit, Indie Hackers, DEV, OKKY, GeekNews, Show HN, Discord, Bluesky, Mastodon이다. 모든 platform preview 구현은 끝났고, 마지막 Phase 18은 전체 회귀와 증거 문서 정리만 남았다.

## 개발 목적

1. 현재 생성·편집한 원고가 각 서비스의 읽기 폭, 줄바꿈, 미디어 비율, 필수 필드에서 어떻게 보일지 가깝게 검토한다.
2. 완성 원고형·사람 작성 보조형·신규 수동 입력형을 구분해, 사실 자료를 완성 게시물처럼 오인시키지 않는다.
3. 다음 플랫폼을 시작하기 전에 직전 플랫폼의 visual·accessibility·안전 회귀를 통과시키는 순차 구현 흐름을 고정한다.

## 개발 범위

- 대상: LinkedIn, Facebook, Instagram, YouTube Shorts, TikTok, Product Hunt, Peerlist, Disquiet, Reddit, Indie Hackers, DEV, OKKY, GeekNews, Show HN, Discord, Bluesky, Mastodon.
- 현재 `publishFields`가 있는 채널은 선택 locale의 현재 원고만 미리본다. 번역 원고가 없거나 stale이면 원문 fallback 없이 빈 상태를 보여준다.

## 공통 진행 규칙

- Phase는 목록 순서대로 하나씩 진행한다. 해당 Phase의 모든 자체 테스트·이슈 정리가 끝나기 전 다음 Phase 코드를 시작하지 않는다.
- 각 Phase 시작 시 공식 문서와 비로그인 공개 UI reference를 다시 확인하고, URL·확인일·viewport를 검증 증거에 기록한다. 정적 screenshot/CSS/asset을 프로젝트에 복사하지 않는다.
- 미리보기는 local rendering only다. `textContent`, same-origin static module, 기존 session state만 사용하며 external fetch·OAuth·connector·social write는 항상 `0회`다.
- target locale이 비어 있거나 stale인 경우 원문 대체·자동 번역·가짜 기본값을 만들지 않는다.
- 실제 서비스와 혼동할 수 있는 account identity·engagement·게시 완료 UI를 넣지 않는다. 상단/하단에 `게시 전 미리보기`와 local-only 고지를 유지한다.
- asset은 session object URL만 사용하며 asset hash와 readiness가 일치할 때만 보인다. local path, object URL, token, secret은 localStorage·approval snapshot·DOM data attribute에 저장하지 않는다.
- `src/x-preview.mjs`와 `src/threads-preview.mjs`는 안정된 구현으로 두고, 처음부터 전 채널 공통 renderer로 리팩터링하지 않는다. 공통화는 두 번째 이상의 실제 중복이 확인될 때에만 최소로 한다.
- 구현 중 재사용 가능한 실패가 발생하면 시간·증상·영향·재현·임시 조치만 현 Phase에 기록하고, 완료 때 `plan-only | existing-reference | new-lesson`으로 분류한다.
