# implement_20260816_192530.md

작성 일시: `2026-08-16 19:25:30 KST`

이 문서는 공개 GitHub 저장소 URL 하나를 입력하면 프로젝트 사실을 읽고 바이럴 콘텐츠 파일을 생성하는 최소 CLI를 구현하기 위한 현재 작업 문서다.

## 개발 목적

다음 한 줄이 실제로 동작하는 MVP를 만든다.

```text
공개 GitHub URL 1개 입력 → 프로젝트 요약 + 3종 바이럴 콘텐츠 생성
```

## 개발 범위

- 입력: `https://github.com/<owner>/<repo>` 형식의 공개 저장소 하나
- 수집: 저장소 metadata, README, license, 선택적 `package.json`
- 분석: 제품명, 설명, 대상 사용자, 기능 최대 5개, 기술, 데모 URL, 한계
- 출력: JSON/Markdown 요약, Hook, Markdown 바이럴 콘텐츠 3종
- 실행: Node.js CLI
- 게시: 사용자가 검토한 뒤 수동 게시

## 제외 범위

- 대상 저장소 파일 수정 또는 PR 생성
- GitHub Sponsors와 `FUNDING.yml`
- SNS 자동·예약 게시
- 데이터베이스와 웹 UI
- 비공개 저장소
- 여러 저장소 일괄 처리
- 이미지·영상 생성
- LLM API 연동과 프롬프트 프레임워크
- 성과 측정 자동화
