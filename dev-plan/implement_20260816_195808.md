# implement_20260816_195808.md

작성 일시: `2026-08-16 19:58:08 KST`

이 문서는 기존 GitHub 분석·콘텐츠 생성 엔진에 사용자가 브라우저에서 조작할 수 있는 단일 화면 GUI를 추가하기 위한 작업 문서다. `memory_node_graph`에서는 이미지나 그래프를 가져오지 않고 시각 테마만 적용한다.

## 개발 목적

다음 흐름을 터미널 없이 브라우저에서 사용할 수 있는 MVP로 만든다.

```text
공개 GitHub URL 입력
→ 저장소 분석
→ 프로젝트 사실 확인
→ 바이럴 콘텐츠 3종 확인·수정
→ 복사 또는 Markdown 다운로드
```

## 개발 범위

- Node.js 로컬 웹 서버와 단일 화면 웹 GUI
- 공개 GitHub 저장소 URL 한 개 입력
- 기존 `github.mjs`와 `content.mjs`를 그대로 호출하는 생성 API
- 저장소명, 설명, 라이선스, 데모, 기술, 기능 요약 표시
- 짧은 소개·커뮤니티 글·상세 소개 탭
- 브라우저 안에서 생성 원고 수정
- 현재 원고 복사와 개별 Markdown 다운로드
- 콘텐츠 3종을 하나의 Markdown 묶음 파일로 다운로드
- `memory_node_graph`에서 추출한 색상·타이포그래피·표면·경계·초점 스타일 적용
- 데스크톱과 모바일 반응형 화면

## 제외 범위

## 결정 기록

- GUI는 설치 의존성이 없는 HTML/CSS/JavaScript로 구현한다.
- 웹 서버는 Node.js 표준 `node:http`를 사용한다.
- 기본 바인딩은 외부 공개가 아닌 `127.0.0.1`로 제한한다.
- GitHub 토큰은 서버 환경변수에서만 읽고 브라우저로 보내지 않는다.
- 생성 결과 수정 내용은 브라우저 메모리에만 유지하며 저장하지 않는다.
- `전체 다운로드`는 브라우저의 다중 다운로드 차단을 피하기 위해 콘텐츠 3종을 하나의 Markdown 파일로 묶는다.
- 테마 적용은 CSS 토큰과 컴포넌트 상태에 한정하며 기존 이미지·그래프·브랜드 마크를 가져오지 않는다.
