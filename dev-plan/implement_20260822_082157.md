# implement_20260822_082157.md

작성 일시: `2026-08-22 08:21:57 KST`

이 문서는 기존 X 원고 검토 화면을, 사용자가 게시 전 실제 줄바꿈·피드 밀도·스레드 흐름을 가늠할 수 있는 **고충실도 로컬 게시물 미리보기**로 재설계하기 위한 작업 문서다.

## 개발 목적

1. X 단일 원고와 스레드를 실제 웹 피드에서 읽는 듯한 폭·위계·줄바꿈으로 검토한다.
2. 기존의 대시보드형 proof sheet를 줄이고, 작성자 행·본문·메타·행동 영역·스레드 연결을 가진 게시물 중심 화면으로 바꾼다.
3. 현재 locale, approval snapshot, stale, 가중 문자, URL 수는 유지하되 실제 게시물로 오인하지 않게 구분한다.

## 디자인 결정

- **대상 사용자:** 게시 직전 원고의 첫 화면·문단 길이·스레드 연결감을 확인하려는 프로젝트 작성자.
- **단일 목적:** “이 원고가 X 피드에서 어떻게 읽힐지”를 한눈에 판단하게 한다.
- **시각 기준:** 최근 X 다크 웹/모바일의 좁은 읽기 열, 1px divider, author→본문→메타→행동 행의 정보 순서를 참고한다.
- **고유 구분:** 상단 `게시 전 미리보기`와 하단 local-only 고지를 유지하고, 실제 게시 상태·반응·결과로 보일 수 있는 정보는 만들지 않는다.
- **시그니처:** 단일안은 독립 post surface, 스레드는 연속 avatar rail과 연결선으로 순서를 즉시 읽게 한다.

## 개발 범위

- X 1·2·3안과 X 스레드의 current locale `publishFields`를 새 미리보기 surface로 렌더
- handle 기반 initials avatar, 작성자 행, `초안 · 게시 전` 메타, 본문, URL wrapping, 가중 문자/URL 진단, 비활성 local action row
- 스레드의 `1/n` label·연속 rail·각 구간 진단
- desktop 600px 읽기 열 및 mobile 390px 미리보기 preset, 실제 320px viewport
- 현재 승인/무효/번역 없음/280 초과 표시와 `textContent` 안전 경계 유지

## 제외 범위

- X 로고·Chirp font·공식 SVG/CSS/스크린샷·iframe/embed 및 실제 X DOM 복사
- 실제 계정 avatar, 인증 badge, 실제 timestamp, 반응·조회 수, Post/Reply/Repost/Like API·링크 동작
- X OAuth, actual publish, upload, scheduling, browser macro, network write
- 다른 채널 미리보기 구조의 공통화 또는 Threads 화면 변경

## 공통 진행 규칙

- 실제 X UI/Post라고 주장하지 않으며 상단에 `게시 전 미리보기` 상태를 표시한다.
- handle·본문 외 실제 계정 정보, 가짜 engagement 수치, 실제 timestamp는 표시하지 않는다.
- 미리보기는 `textContent`와 current locale만 사용한다. 원문 fallback, OAuth, 외부 fetch, social write는 0회다.
- `approved`, `stale`, `empty`, 280 초과 상태는 색만이 아닌 문구로도 구분한다.
- 각 Phase는 자체 테스트가 끝난 뒤 진행한다.
