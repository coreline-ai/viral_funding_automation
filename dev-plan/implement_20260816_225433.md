# implement_20260816_225433.md

작성 일시: `2026-08-16 22:54:33 KST`

이 문서는 초기 계획의 바이럴 채널 범위를 수동 게시용 MVP로 복구하고, 각 채널의 준비 상태를 GUI에서 정직하게 표시하기 위한 개발 범위를 고정한다.

## 개발 목적

1. 전체 채널을 `준비됨·수정 필요·운영 확인·후순위` 상태로 한 화면에 표시한다.
2. Threads, Reddit, X 다중 문안, LinkedIn, Disquiet, DEV, Shorts, Show HN 순으로 실제 초안을 생성한다.
3. 자동 게시나 계정 연동 없이 사람이 검토·복사·다운로드할 수 있는 출시팩을 완성한다.
4. `memory_node_graph` 실제 생성 결과와 Shorts MVP 영상 1개까지 검증한다.

## 개발 범위

- 외부 플랫폼 13개의 상태 인벤토리
- 현재 우선 채널 9개용 원고 또는 게시 준비 문서
- X 단일 게시물 3안과 스레드 1안
- Threads Build in Public 연속 게시
- Reddit 서브레딧 선택 전용 제목·본문·규칙 체크
- LinkedIn 게시물
- 현재 Disquiet 제품 등록·연결 포스트 형식
- DEV 기술 글 보강 게이트
- YouTube Shorts 스크립트·샷리스트와 `memory_node_graph` 세로 MVP 영상
- Show HN 보류 상태의 사람 작성용 영어 초안·체크리스트
- 기존 GeekNews Show 초안·preflight 유지
- 전체 복사·개별/일괄 Markdown 다운로드와 브라우저 저장 복원
