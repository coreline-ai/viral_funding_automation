# YouTube Shorts 게시 준비 초안

상태: `실제 세로 영상 제작·검수 후 게시`

- 권장 규격: 1080×1920, H.264, 15~30초
- 화면: 실제 제품 화면만 사용
- 시청 조건: 무음으로도 이해되는 자막
- 음악: 저작권이 확인된 음원 또는 무음

## 20초 샷리스트

| 구간 | 화면 | 자막 |
|---|---|---|
| 0~3초 | 대표 화면 전체 | AI Systems Atlas, 20초 안에 핵심 화면을 확인해 보세요 |
| 3~7초 | 핵심 그래프·결과 확대 | GPU 발광 그래프 — Three.js 점광·후광·관계선·배경 입자 렌더링 |
| 7~12초 | 탐색·필터·근거 영역 | 3가지 관점 — 별자리, 성운, 선택 노드 중심 궤도 |
| 12~16초 | 구현 또는 근거 화면 | TypeScript · ai · cloudflare-d1 |
| 16~20초 | 대표 화면 + 링크 안내 | AI Systems Atlas · 데모와 GitHub에서 확인하세요 |
