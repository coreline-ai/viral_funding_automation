## 현실적인 사용 순서

1. 첫 게시에는 `final/geeknews-show.md`와 대표 이미지를 사용합니다.
2. 운영자 본인의 말투로 제목과 본문을 마지막으로 검토합니다.
3. `final/publish-checklist.md`를 완료하고 GeekNews `Show`에 직접 등록합니다.
4. 게시 URL과 시각을 기록하고 최소 72시간, 권장 7일 동안 반응을 확인합니다.
5. 이후 Threads → Reddit 자격 확인 → X → LinkedIn·Disquiet → DEV → Shorts → Show HN 순으로 필요한 채널만 진행합니다.

## 게시 가능 상태

- X 3안과 스레드: 가중 문자 검사 통과, 문구·대표 이미지 최종 확인 필요
- Threads·LinkedIn: 수동 게시 원고 준비, 본인 말투 확인 필요
- Reddit: 서브레딧과 계정·규칙 확인 전 게시 금지
- Disquiet: 제품 등록·검토 후 연결 포스트로 사용
- GeekNews: 검토된 최종본 있음, 계정·가입 기간·중복 확인 필요
- DEV: 실제 제작 경험·예제·트레이드오프 보강 전 게시 금지
- Shorts: 실제 영상 제작 완료, 업로드 전 자막·링크·권리 최종 확인 필요
- Show HN: 앞선 피드백 반영과 작성자 영어 재작성 전 보류

모든 등록은 수동입니다. 업보트·Star 요청, 자동 댓글, 동일 원고의 다중 커뮤니티 반복 게시를 하지 않습니다.
