## 계정·채널

- [ ] GeekNews 계정이 링크 등록 요건을 충족한다.
- [ ] `뉴스`가 아니라 `Show` 등록 화면을 사용한다.
- [ ] 동일 저장소의 최근 중복 등록이 없다.

## 원고

- [ ] 제목과 본문을 운영자 본인의 말투로 마지막 검토했다.
- [ ] 공개 데모와 GitHub 링크를 직접 열어 확인했다.
- [ ] 근거 없는 성능·사용자·수익 수치가 없다.
- [ ] Star·업보트·후원을 요청하지 않는다.
- [ ] 현재 한계가 숨겨지지 않았다.

## 대표 이미지

- [ ] `../assets/ai-systems-atlas-live.png`가 정상적으로 열린다.
- [ ] 실제 제품 화면이며 개인정보·토큰·로컬 경로가 보이지 않는다.

## 기준점·게시 기록

- [ ] 게시 직전 Star·Fork·Issue 수를 기록했다.
- [ ] 가능한 경우 GitHub Traffic 화면을 캡처했다.
- [ ] 게시 완료 후 URL과 KST·UTC 시각을 기록한다.
- [ ] 최소 72시간, 권장 7일 동안 두 번째 채널 게시를 보류한다.
- [ ] 삭제·숨김·스팸 지적이 있으면 다음 캠페인을 중단한다.

## 게시 결과

- 게시 시각 KST: `미게시`
- 게시 시각 UTC: `미게시`
- 1차 관측 예정: `게시 후 72시간`
