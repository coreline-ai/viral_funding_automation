# AI Systems Atlas Product Hunt 게시 직전 체크리스트

판정 일시: `2026-08-17 KST`

현재 판정: `초안 생성 가능 / 실제 예약 전 계정·미리보기 확인 필요`

## 1. 완료된 준비

- [x] 제품명 확정
- [x] 직접 실행 가능한 제품 URL 확인
- [x] GitHub와 MIT 라이선스 확인
- [x] 영문 Tagline 확정
- [x] 영문 Description `260자 이하` 확인
- [x] 영문 Maker 첫 댓글 작성
- [x] 실제 제품 화면 Gallery 원본 2장 준비
- [x] 정사각형 SVG Thumbnail 원본 준비
- [x] 가격 `Free`, 상태 `Live` 확인
- [x] 투표 요청·과장 수치·대량 공유 문구 없음

## 2. 사용자 계정 확인

- [ ] 회사 계정이 아닌 개인 Product Hunt 계정으로 로그인
- [ ] 온보딩과 게시 권한 확인
- [ ] 신규 계정이면 1주 대기 또는 현재 공식 안내의 즉시 접근 조건 확인
- [ ] Maker username을 `product-hunt-launch.md`에 입력

## 3. Create Draft 입력

- [ ] 제품 URL을 직접 데모 URL로 입력
- [ ] 제품명은 `AI Systems Atlas`만 입력
- [ ] Tagline과 Description 붙여넣기
- [ ] Pricing `Free`, Status `Live` 선택
- [ ] 실제 UI에서 존재하는 Topic 2~3개만 선택
- [ ] Thumbnail source 업로드 후 정사각형 미리보기 확인
- [ ] Gallery 1·2 업로드 후 제품명·UI 잘림 여부 확인
- [ ] Maker 개인 계정 연결
- [ ] Maker 첫 댓글 붙여넣기
- [ ] 먼저 `Create Draft`로 저장

## 4. 예약 전 확인

- [ ] 데모가 로그인 없이 열림
- [ ] GitHub 링크와 MIT 라이선스가 열림
- [ ] 모바일·데스크톱 Product Hunt 미리보기 확인
- [ ] Gallery가 2장 이상 표시됨
- [ ] Thumbnail 또는 Gallery 크롭이 핵심 제품 화면을 가리지 않음
- [ ] 모든 영문 문구를 운영자 본인의 표현으로 마지막 검토
- [ ] 게시일을 30일 안에서 선택하고 `12:01 AM PST` 시작을 인지
- [ ] 게시 후 댓글에 직접 답할 시간 확보

## 5. 현재 남은 차단 조건

1. Product Hunt 개인 계정과 게시 권한은 웹앱이 자동 판정할 수 없다.
2. SVG Thumbnail의 실제 업로드·크롭 결과는 Product Hunt Create Draft에서 확인해야 한다.
3. 실제 예약은 외부 서비스에 변경을 만드는 작업이므로 사용자 확인 후 진행해야 한다.

위 세 가지를 완료하기 전에는 `게시 준비 완료`로 표시하지 않는다.
