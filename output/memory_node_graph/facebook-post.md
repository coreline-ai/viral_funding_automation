이런 도구를 처음 사용할 때 가장 먼저 확인하고 싶은 정보가 무엇인지 피드백을 받고 싶습니다.

## 게시 전 확인

- [ ] 기존 1080×1920 세로 영상이 실제 제품 화면으로 구성됨
